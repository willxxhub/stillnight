Política de privacidade

Atualizada em 30 de outubro de 2026.

Quem usa

O Stillnight Studio é um aplicativo pessoal para Windows, usado apenas pelo autor para gerir o próprio canal do YouTube. Ele não é oferecido a outras pessoas e não tem servidor próprio.

Dados do Google e do YouTube

Com a autorização do dono do canal, o aplicativo usa a API do YouTube (YouTube API Services) para:

  • enviar vídeos, títulos, descrições e miniaturas ao canal;
  • ler informações e métricas do próprio canal (visualizações, tempo assistido, inscritos, alcance e, se autorizado, receita).

Esses dados ficam guardados só no computador do autor. A chave de acesso do Google é protegida pela criptografia do Windows (DPAPI). Nada é vendido, compartilhado para publicidade ou enviado a servidores do aplicativo, que não existem.

Para planejar os próximos vídeos, resumos dessas métricas podem ser enviados ao serviço de IA que o autor configurou (OpenAI pelo Codex CLI, ou DeepSeek), sujeitos às políticas desses serviços.

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Termos e controle

  • Ao usar o aplicativo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
  • Apagar a pasta de dados do aplicativo no computador remove todas as informações guardadas.

Contato

Pelo e-mail de suporte mostrado na tela de autorização do Google, ou abrindo uma issue no GitHub.

In English

Stillnight Studio is a personal Windows app used only by its author to manage their own YouTube channel. With the channel owner's consent it uses YouTube API Services to upload videos, titles, descriptions and thumbnails, and to read the channel's own information and analytics. This data stays on the author's computer (the Google token is encrypted with Windows DPAPI); it is never sold, used for advertising or sent to app servers (there are none). Summaries of channel analytics may be sent to the AI service the author configured (OpenAI via Codex CLI, or DeepSeek) to plan future videos. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using the app you agree to the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions. Contact: the support e-mail shown on the Google consent screen, or a GitHub issue.
